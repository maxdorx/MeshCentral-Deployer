# MeshCentral Deployer

A small native C++ Windows service that discovers Windows computers in Active Directory and installs one configured MeshCentral Windows agent wherever the `Mesh Agent` service is missing. It has no web UI and cannot deploy arbitrary software.

## How it works

1. Searches the configured Active Directory domain or OU subtrees for enabled Windows computer accounts.
2. Checks due computers over SMB and the Windows Service Control Manager (SCM) RPC interface.
3. Does nothing when a configured Mesh Agent service already exists.
4. Otherwise copies `MeshAgent.exe` and a restricted native helper to a unique directory through `ADMIN$` and verifies both copies with SHA-256.
5. Runs the helper as a temporary LocalSystem service. The helper can only execute the adjacent `MeshAgent.exe -fullinstall` command.
6. Verifies that the Mesh Agent service was created, then removes the temporary service and staged files.
7. Retries offline or failed computers with capped exponential backoff.

AD discovery defaults to every 15 minutes. Computers with an installed agent are rechecked every 24 hours, so a subsequently removed agent is installed again on its next check. The deployer host is automatically excluded.

## Requirements

- x64 Windows 10/11 targets and a domain-joined Windows Server 2022 or Windows 10/11 deployer host.
- A dedicated `DOMAIN\user` with read access to the selected AD computer objects and local Administrator rights on every target. Do not use a Domain Admin account.
- TCP 445 for `ADMIN$`, TCP 135, and the configured dynamic RPC range from the deployer to targets.
- A Windows Mesh Agent generated by your MeshCentral server.

## Install

Build the project, then run `artifacts\MeshCentral-Deployer.exe` as Administrator. The terminal installer asks for:

- the service account and password;
- the local path to `MeshAgent.exe`;
- the whole domain or one or more OU distinguished names;
- discovery/concurrency settings and optional plaintext logging.

The selected agent is copied into the installation directory; it does not need to remain on a UNC share. The password is stored only by Windows SCM and is never written to configuration, SQLite, or logs.

State is stored in `C:\ProgramData\MeshCentral Deployer\state.db`. Optional plaintext logging defaults to `C:\ProgramData\MeshCentral Deployer\deployer.log`, rotates at 5 MiB, and keeps one backup.

## Build

Install Visual Studio 2022 with **Desktop development with C++** and a current Windows SDK, then run:

```bat
scripts\build-native.cmd
```

The script builds the statically linked service, restricted remote helper, terminal installer, and native tests. The finished installer is `artifacts\MeshCentral-Deployer.exe`. No .NET runtime or third-party deployment tool is required.
